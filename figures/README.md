# Figures

The folders are named after the figures of the paper.

- [fig2/](fig2/): Fig. 2, logical error rates. The two-panel fitted comparison, with its X/Z-averaged data and refitting workflow.
- [fig3/](fig3/): Fig. 3, panels a and b. Physical-qubit overhead and atom-routing time.

Each folder contains its plotting code, notebooks, numerical tables, and
supplied PDF. Running a plotting script rewrites the PDF (and, for Fig. 3,
the table) in that folder; figures have no separate `results/` folder.
Plotting uses Matplotlib's bundled DejaVu Sans font.
